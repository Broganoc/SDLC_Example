# Test Plan

## Purpose
Check that the appointment system meets approved requirements.

## Example Test Cases
| ID | Scenario | Expected result |
|---|---|---|
| TC-01 | Student searches an available subject and date | Matching open times appear. |
| TC-02 | Two students attempt to book the same time | Only one booking succeeds. |
| TC-03 | Student tries to view another student’s appointment | Access is denied. |
